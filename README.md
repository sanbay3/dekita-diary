# できたこと日記

## 概要

Next.js（App Router）で作った「できたこと日記」アプリです。
その日にできたこと・達成したことを記録していく日記アプリで、記録は日付ごとにグループ化して表示されます。
入力した記録はブラウザのlocalStorageに保存されるため、ページを再読み込みしても消えません。

## 機能

- できたことの記録・削除（カテゴリー: 学習 / 仕事 / 趣味 / その他）
- 日付ごとにグループ化して表示（新しい日付が上）
- キーワード・カテゴリーによる検索・フィルター
- 連続記録日数（ストリーク）の表示
- 今月の記録件数の統計
- localStorageによるデータ永続化（ページ更新後も保持）
- モバイル対応のレスポンシブデザイン

## 使用技術

- Next.js（App Router）
- React（useState / useEffect）
- JavaScript（TypeScriptは未使用）
- Tailwind CSS
